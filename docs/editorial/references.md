## How the grid is used

- **Writer prompt**: each block of the note anatomy maps to one reference above.
- **Final judge**: scores structural completeness against this grid — missing
  blocks are named defects, not style preferences.
- Criteria are structural (presence, order, honesty markers) — never textual
  imitation of the referenced publications.
